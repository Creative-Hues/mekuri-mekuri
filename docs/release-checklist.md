# 公開前の確認項目(めくりめくり)

公開(バージョンを上げて main に push)する前に、この順で確認する。
確認する端末:**iPhone 実機(Safari・ホーム画面から起動)**、**PC の Chrome**(デバイスモードで Android 表示も)。
表示:**1ページ表示(スマホ縦)** と **見開き表示(スマホ横・PC)** の両方。

## 0. 自動で確認すること

- [ ] `npm test` がすべて通る
- [ ] `npm run build` が通る
- [ ] package.json の version を上げた(アプリの設定画面に出る)
- [ ] データ構造を変えたなら、マイグレーションと `docs/data-model.md` を更新した

## 1. 初めて使う人

- [ ] データのないブラウザ(シークレットウィンドウなど)で開くと、使い方説明が出る
- [ ] 使い方説明:次へ・戻る・スワイプ・スキップ・はじめる が使える。最後のカードに案内文が出る
- [ ] 閉じたあと再読み込みしても、もう出ない
- [ ] 前から使っている端末では、更新後も出ない
- [ ] 設定画面の「使い方を見る」で、いつでも出せる

## 2. 書く

- [ ] ノートの作成・タイトルの変更・ページの追加・スワイプ/矢印でのページ送り
- [ ] 見出し・トグル見出し・リスト・ToDo・太字・取り消し線・文字色・ライン・マーカー
- [ ] 表(「＋」で行・列を追加、セルの長押しメニュー)
- [ ] 画像:ツールバーから選ぶ/貼り付け(PC)/ドロップ(PC)。表の中には入らない
- [ ] Webリンク・別ノート/別ページへのリンク(押すと移動)
- [ ] 付箋:追加・移動・大きさ・色・削除
- [ ] 目次から見出しへ移動
- [ ] スマホ:ツールバーがキーボードのすぐ上に出る
- [ ] PC:ショートカットキー(日本語キーボードでも)。設定画面の一覧と合っている
- [ ] 元に戻す・やり直しが、上のすべての操作に効く
- [ ] ヘルプ(ノート画面・本棚の ?):ボタンがすべて載っている。PC はマウスの操作とショートカット、スマホは指での操作だけが出る。PC は右から、スマホは下から出る。本棚のヘルプから使い方説明を開ける
- [ ] 最初の使い方説明:PC とスマホで、それぞれの操作の説明になっている
- [ ] 設定のショートカットキーの一覧:スマホでは閉じた状態、PC では開いた状態から始まり、押すと開閉する
- [ ] ボタンの名前:PC はマウスを乗せると、スマホは長押しで出る。長押ししたボタンは押されない。行のハンドルの長押し(選択モード)は今までどおり

## 3. 整理

- [ ] 行のドラッグ・複数選択での移動・別ページへの移動
- [ ] ページ・本棚のノートのドラッグでの並び替え
- [ ] お気に入り(本棚の上の段)
- [ ] ゴミ箱:ノート・ページを入れる/戻す/完全に削除
- [ ] 全ノート検索(Ctrl+F / ⌘+F)、結果を押すとその場所へ移動

## 4. デザイン

- [ ] 表紙(ベース色・サブ色・柄・柄の大きさ・文字の配置・タイトルの文字色・書体)、紙の色、縁。本棚・ゴミ箱・デザインの見本に同じ表紙が出る
- [ ] 本文の書体(表紙と同じ/ゴシック/明朝/丸ゴシック)が本文・付箋・PDF に反映される
- [ ] 文字サイズ(5段階):設定画面・ノートの「…」メニュー・Ctrl(⌘)+「+」「-」。再起動しても残る
- [ ] ダークモード:自動(端末に合わせる)/ライト/ダーク。色を選んだ紙はその色のまま
- [ ] ボタンの文字が読める。白い背景の上でも紙の境目がわかる
- [ ] アイコン:ホーム画面(iPhone・Android)・ブラウザのタブ・共有したときの画像が新しいもの
- [ ] 絵文字・記号が、iPhone と Android で同じように見える

## 5. 書き出しとバックアップ

- [ ] 書き出し:PDF(印刷画面から保存)・Word・Markdown・テキスト。iPhone ではファイルに保存できる
- [ ] バックアップの書き出し → 別の端末(またはブラウザ)で「追加する」で読み込める(画像も)
- [ ] 「置き換える」:先に書き出すかを聞かれる。キャンセル/書き出さずに/書き出してから が正しく動く
- [ ] 前回のバックアップから7日たつと案内が出る(端末の日付を進めて確認)
- [ ] 設定画面の「消されにくい保存」が、ホーム画面から開いたときに「有効」になる

## 6. 更新・オフライン

- [ ] 新しいバージョンを公開すると「新しいバージョンがあります」が出る。iPhone の縦画面で文字が折り返されていない
- [ ] 「更新する」で新しいバージョンになり、ノートが残っている
- [ ] 機内モードでもホーム画面から起動でき、書ける

## 7. 不具合報告とプライバシー

- [ ] 設定画面の「不具合を報告する」:送る情報が表示され、Googleフォームがバージョンと端末の情報を入力済みで開く。内容の欄は空
- [ ] 「データとプライバシー」の説明が、実際の動きと合っている

## 8. 公開の情報

- [ ] ホーム画面に追加したときの名前とアイコン
- [ ] 共有したときの表示(タイトル・説明・画像)
- [ ] README の内容が今の機能と合っている

## 9. 公開後

- [ ] GitHub の Actions で「テスト」「ビルド」「公開」が成功している
- [ ] 公開された URL で、設定画面のバージョンが新しくなっている
