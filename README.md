# めくりめくり

シンプルでデザイン性の高いノートアプリです。ノートを本棚に並べ、中のページを左右にめくって書きます。

**アプリを開く:https://creative-hues.github.io/mekuri-mekuri/**

## できること

- ページを左右にめくるノート(スマホ縦は1ページ、横画面・PC は見開き)
- 見出し・トグル見出し・リスト・ToDo・文字の色・ライン・マーカー・表・画像・リンク
- ページに貼れる付箋、見出しから作る目次
- ページ・行・付箋・本棚のノートは、すべてドラッグで並び替え
- 表紙・紙の色・縁のデザイン、お気に入り、ダークモード
- 全ノート検索、ゴミ箱(30日で自動削除)
- 書き出し:PDF・Word・Markdown・テキスト
- スマホはキーボードのすぐ上のツールバー、PC はショートカットキーで操作

## 使い方

1. 上の URL を開き、ホーム画面に追加すると、アプリのように使えます(オフラインでも動きます)
   - iPhone:Safari の共有ボタン →「ホーム画面に追加」
   - Android:Chrome のメニュー →「ホーム画面に追加」(または「アプリをインストール」)
   - PC:Chrome・Edge のアドレスバーのインストールボタン
2. 本棚の「新しいノート」からノートを作ります
3. 初めて開いたときに使い方の説明が出ます。設定画面の「使い方を見る」からいつでも見直せます

## データについて

- ノートはこの端末のブラウザの中(IndexedDB)だけに保存します。サーバー・ログイン・同期はありません
- 端末の故障などに備えて、設定画面からバックアップファイルを書き出してください
- バックアップファイルを使えば、スマホからPCへノートを移すことができます。自動で同期したい場合は、ご自身でクラウドサービスをご利用ください
- 不具合報告は Googleフォーム(Googleのサービス)を通して送られます。送るのはフォームに書いた内容と、アプリのバージョン・端末の情報だけで、ノートの中身は送りません

## 開発

```sh
npm ci          # ライブラリを入れる
npm run dev     # 開発用サーバーを起動
npm test        # 自動テスト
npm run build   # 公開用にビルド(dist/)
```

- main に push すると、GitHub Actions がテストとビルドを行い、GitHub Pages に公開します(テストが失敗したら公開しません)
- 仕様は `めくりめくり_計画書.md`、作業のルールは `CLAUDE.md`、データ構造は `docs/data-model.md`、公開前の確認項目は `docs/release-checklist.md`
- 使っている主なライブラリ:React・TipTap(エディタ)・Dexie(IndexedDB)・dnd-kit(ドラッグ)・docx(Word の書き出し)・vite-plugin-pwa
